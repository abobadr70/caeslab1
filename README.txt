موقع شركة دقة المعايرة — نسخة جاهزة لـ GitHub Pages

1) فك الضغط.
2) ارفع جميع الملفات والمجلدات الموجودة داخل هذا المجلد إلى Repository جديد.
3) يجب أن يكون index.html في الجذر مباشرة، ومجلد images بجانبه.
4) من Settings > Pages اختر Deploy from a branch ثم main و / (root).
5) احفظ وانتظر نشر الموقع.

الملفات الرئيسية:
- index.html
- about.html
- services.html
- projects.html
- soil-reports.html
- contact.html
- style.css
- script.js
- images/ (الشعار والصور الميدانية)

تم اعتماد صور الأعمال الميدانية من بروفايل الشركة المرفق.
